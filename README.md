# يومية الكافيتريا

تطبيق موبايل (PWA) لتسجيل اليومية بدل الورقة: إيرادات، مصروفات، ربح اليوم، والباقي بيترحّل لليوم اللي بعده.
كل البيانات بتتحفظ على الموبايل نفسه (localStorage) ويشتغل من غير نت.

## تشغيله على الموبايل
1. ارفعي الفولدر على GitHub Pages (Settings ← Pages ← Branch: main).
2. افتحي الرابط من Chrome على الموبايل ← القائمة ⋮ ← "إضافة إلى الشاشة الرئيسية"
   (على آيفون: Safari ← زر المشاركة ← Add to Home Screen).

## مهم
- خدي نسخة احتياطية من تبويب "نسخ احتياطي" كل أسبوع.
- لو عدّلتي أي ملف، غيّري رقم `CACHE` في `sw.js` عشان التحديث يوصل للموبايل.
